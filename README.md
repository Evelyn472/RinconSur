# Rincón Sur

**Aplicación móvil para la gestión de movimientos de visitantes de un centro comercial.**

## Descripción

Rincón Sur es una aplicación Android desarrollada para registrar y consultar los movimientos de entrada y salida de visitantes de un centro comercial.

## Funcionalidades

- Inicio de sesión y registro de usuarios.
- Registro conjunto de entrada y salida.
- Selección de puertas de acceso y salida.
- Registro de sexo, rango de edad y tipo de flujo.
- Registro de cantidad de acompañantes.
- Consulta de movimientos registrados.
- Edición y eliminación de movimientos.
- Almacenamiento local de información.
- Registro automático de fecha y hora.

## Tecnologías utilizadas

- Kotlin
- Android Studio
- Jetpack Compose
- Material Design 3
- Room Database
- ViewModel
- Git y GitHub

## Almacenamiento

La aplicación utiliza Room Database para almacenar localmente los movimientos registrados.

## Cómo ejecutar el proyecto

1. Clonar el repositorio desde GitHub.
2. Abrir el proyecto en Android Studio.
3. Esperar a que finalice la sincronización de Gradle.
4. Iniciar un emulador Android o conectar un dispositivo.
5. Presionar Run para ejecutar la aplicación.
